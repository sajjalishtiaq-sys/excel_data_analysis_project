# SuperMart Sales Analysis (Excel)

A data analysis workbook built from 420 sales transactions, with 3 dashboards for 3 different business teams. Built using Pivot Tables, PivotCharts, calculated fields and data cleaning.

## Project 1: Regional Sales Performance
**Requested by:** Regional Sales Head
**Brief:** Which region and category generate the most Net Sales, how sales trend month over month, and how much discounts affect Net Sales.

![Regional Sales](1_regional_sales.png)

## Project 2: Payment Mode & Revenue Reconciliation
**Requested by:** Finance Team
**Brief:** Transaction volume by payment mode (for gateway charges), revenue by payment mode, and how much revenue is lost to discounts.

**Key insights:**
- Discounts are about 8% of gross revenue (Rs 367,830 of Rs 4,609,110).
- Credit Card has the highest discount rate (9%).
- Debit Card brings in the most gross revenue.

![Revenue Reconciliation](2_revenue_reconciliation.png)

## Project 3: Sales Rep Performance & Incentive Review
**Requested by:** Sales Manager
**Brief:** Which rep generated the most Net Sales, which category each rep is strong in, and how consistent each rep is (orders closed).

![Sales Rep Performance](3_sales_rep_performance.png)
